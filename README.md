# Monthly Expense Tracker

## About This Project

I made this small Python project to keep track of my monthly expenses and see where most of my money is being spent. Sometimes it becomes hard to manage spending properly, so I wanted to create something simple that could calculate everything automatically for me.

This project stores different expense categories like food, transport, books, internet, and clothing. It then calculates the total amount spent, how much money is left from my monthly income, and also shows the highest and lowest expenses.

I also added a small advice section that gives a message depending on how much money is left after spending.

---

## Features

* Tracks monthly expenses
* Calculates total spending
* Shows remaining money after expenses
* Finds highest expense category
* Finds lowest expense category
* Gives simple budget advice

---

## Technologies Used

* Python
* Pandas Library

---

## How It Works

1. The expense data is stored in a dictionary.
2. Pandas is used to create a table from the data.
3. The program calculates:

   * total money spent
   * remaining balance
   * highest expense
   * lowest expense
4. At the end, the program prints a short advice message based on the remaining balance.
